# 🚀 INICIO RÁPIDO - ViniloStore

## En 30 segundos

### 1. **Inicia la aplicación**
```bash
npm run dev
```
La app abrirá en `http://localhost:5173`

### 2. **Login con demo**
- Email: `admin@vinilo.com`
- Contraseña: `admin123`

### 3. **Explora las pestañas**
- Dashboard → Ver bienvenida
- Productos → Ver catálogo y filtrar
- Admin → Crear/editar productos (admin only)
- Perfil → Ver tu información

---

## 🎯 Funciones Principales

| Acción | Cómo Hacerlo |
|--------|-------------|
| **Registrarse** | Haz clic en "Registrarse" en login |
| **Agregar al carrito** | En Productos, haz clic "Añadir" |
| **Ver carrito** | Botón "Carrito" en la esquina superior |
| **Crear producto (admin)** | Admin → "+ Nuevo Producto" |
| **Filtrar productos** | En Productos, usa los filtros |
| **Cerrar sesión** | Botón "Logout" superior derecha |

3. **Borra localStorage** (DevTools → Application → Storage)
4. **Reinicia npm run dev**
